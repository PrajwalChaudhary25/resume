# How to use rendercv
## Installation
```
 pip install "rendercv[full]"
```

## create
```
  rendercv new "john doe"
```

- A new yaml file with filename john_doe_CV.yaml will be created.
- create your resume using rendercv syntax

## Render
```
  rendercv render "john_doe_CV.yaml"
```

If you need more help please visit [rendercv docs](https://docs.rendercv.com/)
